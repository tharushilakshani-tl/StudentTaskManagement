# Library Management System

## 1. Project Overview

The Library Management System is a small web-based application developed as part of the Software Configuration Management (SCM) practical.

The system aims to simplify basic library operations, such as adding books, viewing available books, borrowing books, and removing books from the library collection.

This project focuses on applying SCM practices throughout the software development process, including version control, configuration item identification, documentation, and team collaboration.

## 2. Project Objective

The main objective of this project is to develop a simple and user-friendly web application that helps manage library book records and basic borrowing activities.

The project also aims to demonstrate effective Software Configuration Management practices using Git and GitHub, including tracking changes, maintaining version history, and collaborating as a team.

## 4. Main Features

The application is intended to support the following features:

* Add new books to the library collection.
* View the list of books.
* Borrow books.
* Remove books from the collection.
* Track book availability.
* Provide a simple interface for managing library records.

Additional features may be introduced as the project develops.

## 7. Basic Setup Instructions

### Prerequisites

Ensure that the following software is available:

* Git
* Visual Studio Code or another code editor
* A modern web browser
* A GitHub account with access to the team's repository

### Running the Application

1. Clone the team's GitHub repository or obtain the project files.
2. Open the project folder in Visual Studio Code.
3. Navigate to the `src` directory.
4. Open `index.html` in a web browser.
5. Interact with the application to test its available features.

The initial version is a basic frontend application using HTML, CSS, and JavaScript. Additional technologies may be introduced if required by future project development.

## 8. Version Control and SCM

Git is used to track changes to project files and maintain the project's version history.

GitHub is used to host the shared repository and support team collaboration.

The team follows these SCM practices:

* Maintain a single Git repository throughout all practical sessions.
* Track source code and documentation changes using Git.
* Use meaningful commit messages.
* Maintain the configuration item register in `docs/scm-record.md`.
* Review and test changes before accepting them.
* Keep the project documentation updated as the application evolves.

## 9. Project Scope

This project is intended for educational purposes and demonstrates the development and management of a small web-based application.

The application is not intended to be production-ready. The primary assessment focus is on applying Software Configuration Management practices throughout the project lifecycle.
